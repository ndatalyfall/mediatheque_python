# Médiathèque en Python

Gestion d'une petite médiathèque avec des livres et des DVD, adherents, emprunts et rendus. Projet POO avec héritage, abstraction, polymorphisme et encapsulation.

## Lancer la démonstration

```bash
python main.py
```

## Lancer les tests

```bash
pytest -q
```
